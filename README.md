# Bo-Ning Li

Artist & technologist working with simulation, generative systems, and emergence.

I build computational systems — and the tools that make them. Houdini artist and technical generalist, previously at [VolvoxLabs](https://www.volvoxlabs.com) in Brooklyn; recent work includes OFFF Barcelona, permanent LED installations in Midtown Manhattan, and content for the Sphere in Las Vegas.

Alongside studio work, an open-source practice reoriented around AI — coding agents for Houdini and TouchDesigner, a Copernicus toolkit featured by SideFX, and ongoing experiments with neural cellular automata as a design material.

The recurring question: how is form encoded — as physical law, as parametric rule, as learned behavior. 

## 01 — Open Source

- [**motion-cops**](https://github.com/Boning1011/motion-cops) — Houdini toolkit that turns Copernicus into a motion-design powerhouse: one-click pixel sorting, solver workflows, real-time effects. Featured by SideFX.
- [**houdini-agent**](https://github.com/Boning1011/houdini-agent) — production-tested AI coding agent for Houdini.
- [**touchdesigner-agent**](https://github.com/Boning1011/touchdesigner-agent) — AI coding agent for TouchDesigner.
- [**houdini-fab**](https://github.com/Boning1011/houdini-fab) — HDA collection for digital fabrication workflows.

## 02 — Research

Neural cellular automata as a design material: tiny physics-inspired update rules trained as competing species on a shared grid — a study in how ecosystem-level behavior emerges from minimal local rules. Write-ups and process notes live at [boningli.com/rnd](https://boningli.com/rnd).
